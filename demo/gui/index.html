About ArchiveWise

This is a local simulation of the ArchiveWise review flow, styled after the UGREEN UGOS desktop. It is not the Uliya Skill runtime.

It reads a local folder, finds byte-identical duplicates, extracts text-document fields, and records approved tags in archivewise-tags.json. Reviewed files are never modified.

The submitted Skill runs on UGREEN NAS through registered file and document experts.
